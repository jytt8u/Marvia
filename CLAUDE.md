# Marvia — правила для Claude

Инфраструктура для продавца доступа: свой протокол VP1, нода, панель, клиенты
под Windows и Android. Один автор, публичный репозиторий, версия до 1.0.

Читай этот файл целиком перед первой правкой. Он не про стиль кода — он про то,
почему проект написан так, а не иначе.

---

## Язык

Всё на русском: комментарии, имена в интерфейсе, сообщения об ошибках,
сообщения коммитов, документация. Имена идентификаторов — английские.
Сообщения об ошибках — с маленькой буквы, без точки, как принято в Go.

## Главные запреты

1. **Своих криптопримитивов нет и не будет.** X25519, ChaCha20-Poly1305,
   BLAKE2s через `github.com/flynn/noise`. Ничего самодельного в криптографии.
2. **Нарисованная кнопка — это обещание.** Не добавляй в интерфейс элемент,
   за которым нет действия. Если экран из макета содержит кнопку, которой
   нечем работать, — кнопку не переносим, а в сообщении коммита пишем, что
   не перенесли и почему.
3. **`Prologue = "veil/vp1"` в `internal/vp1/handshake.go` не трогать.** Это
   строка на проводе, по сути версия протокола: изменение молча ломает
   совместимость со всеми установленными клиентами. Переименование проекта
   сюда не распространяется.
4. **Миграционный код в `scripts/install-panel.sh` не чистить.** Он про чужие
   старые установки под именем veil и обязан остаться.
5. **Нода не знает лишнего.** Нет базы пользователей, нет списка других нод,
   нет журнала «кто куда ходил». Потеряв панель, нода продолжает работать по
   последнему известному состоянию. Любая правка, которая добавляет ноде
   память о людях, — против архитектуры.
6. **Секреты не попадают в историю.** `.gitignore` перечисляет ключи, базы,
   учёт трафика, keystore. Не добавляй файлы в обход него.

## Комментарии

Комментарий объясняет **зачем**, а не что. Так написан весь проект —
не ломай интонацию:

```go
// Prologue подмешивается в хеш хендшейка с обеих сторон. Если строки не
// совпали — хендшейк просто не сойдётся. Меняя её, мы намеренно ломаем
// совместимость: это, по сути, версия протокола.
```

У каждого нетривиального решения в комментарии стоит причина и цена
альтернативы. Комментарий вида «увеличиваем счётчик» не нужен.

## Сообщения коммитов

Заголовок — законченное утверждение на русском, о поведении, а не о коде:
«Клиент замечает смерть ноды по трафику, а не по расписанию», а не «фикс
failover». Тело — несколько абзацев: что было сломано или невозможно, что
стало, какое решение и почему именно оно, что намеренно не сделано.

Никаких подписей инструмента: ни `Co-Authored-By` в коммитах, ни «Generated
with …» в описаниях PR. Автор у проекта один, и в истории он один.

Ветка на задачу, PR **в main** (не в ветку-предка: так три PR подряд
терялись), merge в main. Прямо в main не коммитим.

## Тесты

```bash
go test ./...      # обязателен перед PR
go vet ./...
go build -o bin/ ./...
```

Тест проверяет обещание, а не реализацию: «повтор оплаты не выдаёт второй
доступ», «каждый элемент, который ищет код, есть в разметке». Имя теста —
предложение. Если правка чинит баг — сначала тест, который на этом баге
краснеет.

## Карта проекта

| Где | Что |
|---|---|
| `internal/vp1/` | протокол: хендшейк, кадры, добивка. Самое опасное место |
| `internal/transport/` | камуфляж: uTLS, REALITY, WebSocket, QUIC |
| `internal/inbound/` | VLESS и Trojan рядом с VP1 — путь миграции с чужих панелей |
| `internal/panel/` | панель: `store.go` (SQLite), `api.go` (маршруты `/api/v1`), `web/index.html` |
| `internal/client/` | ядро клиента: подписка, замер нод, переезд на живую |
| `cmd/marvia-node`, `cmd/marvia-panel` | то, что стоит на серверах продавца |
| `cmd/marvia-windows/` | клиент ПК: Go + WebView2, интерфейс в `ui/app.html` |
| `android/`, `mobile/` | Android-приложение и Go-мост под gomobile |
| `docs/` | `protocol.md`, `architecture.md`, `guide.md`, `bot.md` |

## Документация — часть правки

Правка, меняющая поведение, обновляет соответствующий документ в том же PR.
В README есть таблица «что уже работает» и абзац «чего пока нет» — они должны
оставаться правдой. Честность списка «чего нет» — часть продукта: она же
единственная защита от продажи несуществующего.

## Чего проект не делает (и предлагать не надо)

Панель на телефоне. Свой платёжный шлюз. Хостинг нод за продавца.
Причины — в конце README, они продуманы.

## Правовая рамка

Разработка и личное использование средств обхода блокировок в России не
криминализованы; с 2024 года действуют штрафы за рекламу и популяризацию.
Поэтому в текстах проекта — описание возможностей, а не призывы и не реклама.
