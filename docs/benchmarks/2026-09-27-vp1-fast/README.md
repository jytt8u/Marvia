# VP1 Fast: локальные замеры 27.09.2026

Две последовательные серии по семь прогонов каждого режима. **Прирост Fast
относительно VP1 по медианам: +7.50% и +6.00%.**
Это небольшой выигрыш на этом стенде; превосходства над VLESS или Trojan
по пропускной способности здесь нет.

МБ/с, десятичные; медиана и полный диапазон min–max. Больше — быстрее.

Все прогоны сохранены, включая высокие значения первых прогонов VP1, TLS,
VLESS и Trojan. Стенд не изолирован от фоновой нагрузки и изменения частот
процессора; разброс заметен. Повторная серия служит проверкой воспроизводимости,
а не заменяет первую. Статистическая значимость отдельно не оценивалась.
С результатами 26 сентября абсолютные скорости напрямую не сравниваются:
это другая серия измерений с другим состоянием машины.

## Условия

- Windows amd64, Go 1.26.6, 16 логических CPU, GOMAXPROCS=16.
- Измеряется исходный код VP1 Fast experimental-1 из коммита, содержащего этот отчёт.
  Родитель исходной реализации: d6e01d18a767a916d5ef203569a9d91c06d9a942.
- Один клиент и один сервер на TCP loopback; направление сервер → клиент.
- По 512 МиБ полезных данных на режим и прогон; прогрев 8 МиБ.
- Одинаковый TLS 1.3, X25519 и TLS_AES_128_GCM_SHA256 для защищённых режимов.
  Внутри VP1 — ChaCha20-Poly1305, внутри Fast — AES-256-GCM.
- Порядок режимов сдвигается каждый прогон. Передача проверяется по содержимому.
- Хендшейк исключён из измерения пропускной способности. После передачи —
  1000 последовательных echo по 1400 байт; среднее время каждого прогона в JSONL.
- VLESS и Trojan — реализации Marvia, не внешние Xray или Trojan.
- Интернет, TUN, потери пакетов, Android, батарея и противодействие DPI не измерялись.

## Повторить

```sh
go build -o marvia-bench ./cmd/marvia-bench
./marvia-bench -experimental -rounds 7 -mib 512 -echoes 1000 -revision YOUR_COMMIT > series-1.jsonl
./marvia-bench -experimental -rounds 7 -mib 512 -echoes 1000 -revision YOUR_COMMIT > series-2.jsonl
```

Fast — отдельный эксперимент, а не новый режим в выпущенном приложении.
[Устройство протокола, проверки и ограничения](../../vp1-fast.md).

## Проверка исходного кода

Локально на Windows пройдены `go test ./...`, `go vet ./...`,
`go build -o bin/ ./...` и `go test -race -count=1 -timeout=5m
./internal/vp1 ./internal/users ./cmd/marvia-bench`.
Проверки не заменяют независимый аудит и испытания на мобильных устройствах.
