## Marvia 1.0

Android и Windows-клиенты, панель и ноды — один открытый комплект. Пользователь
добавляет свой ключ; приложение выбирает ноду или подключается к выбранной
вручную. Панель управляет доступом, но не стоит на пути VPN-пакетов.

В этом выпуске выбранная нода подключается без ожидания замера всех остальных.
Windows-клиент получил первый экран выбора языка и объяснение границ
приватности; длинные записи больше не растягивают журнал. VP1 передаёт крупные
кадры без лишней записи TLS: в [локальном тесте](https://github.com/jytt8u/marvia/blob/v1.0.0/docs/benchmarks/2026-09-26-record-fit/README.md)
пропускная способность выросла на 55,9% к прежней сборке VP1. Это не замер
скорости интернета.

Начиная с 1.0, API бота, ссылки `marvia://` и формат подписки сохраняют
обратную совместимость в рамках 1.x.
