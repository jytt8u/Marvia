## Marvia 1.0.1 — быстрее повторное подключение

Если сохранённому списку нод больше суток, Android и Windows теперь сначала
подключаются к рабочей ноде из него. Панель обновляет список в фоне и больше
не задерживает подключение своим ответом до 20 секунд. Если старая нода
молчит, запрос свежего списка идёт одновременно с её проверкой.

Истёкшая подписка из кэша не принимается: клиент запрашивает актуальные
данные у панели. Формат ключей, шифрование и серверная часть не менялись.

- [Android APK](https://github.com/jytt8u/marvia/releases/download/v1.0.1/marvia-android.apk) — подписан тем же сертификатом, обновляется поверх 1.0.0.
- [Windows EXE](https://github.com/jytt8u/marvia/releases/download/v1.0.1/marvia-windows.exe).
- [Android AAB](https://github.com/jytt8u/marvia/releases/download/v1.0.1/marvia-android.aab) — для будущей публикации в Google Play.
- [Панель, ноды и контрольные суммы](https://github.com/jytt8u/marvia/releases/tag/v1.0.1).

Все тесты Go и тест с детектором гонок для подключения прошли. Длительность
подключения на конкретной мобильной сети и финской ноде ещё нужно проверить
на телефоне. Google Play пока не опубликован, Windows EXE без подписи издателя.
