# Что проверяет GitHub

Жёлтый значок означает очередь или выполнение, зелёный — успешное завершение,
красный — ошибку. Проверки запускаются на каждом push в `main` и pull request.
Они ничего не устанавливают на серверы и не публикуют APK.

| Проверка | Что проверяется |
|---|---|
| Тесты и сборка | Go-тесты, vet, форматирование, интерфейсы, сборки Linux/Windows |
| Windows — сокеты и клиент | Сетевые пути и клиент на Windows |
| Android — ядро, тесты и приложение | Свежее Go-ядро, Kotlin-тесты и сборка APK |
| Зависимости — Linux и Windows | Известные уязвимости с достижимыми символами, govulncheck |
| Фаззинг — четыре отдельных задания | По 60 секунд случайных входов для кадров, добивки, адресов и датаграмм |
| VP1 — подмена, повторы и гонки | Ключи, защита от повторов, целостность потока, параллельный доступ |
| Панель, снимки доступа и обновления — безопасность | Права API, зашифрованные снимки, отзыв доступа, доверие к релизам |

Всего **11 заданий**: 3 сборочных/общих и 8 в workflow безопасности.
Четыре задания фаззинга выполняются независимо: ошибка одного не скрывает
результаты остальных. При найденном сбое входные данные сохраняются артефактом.

## Дополнительные сценарии атак

Добавлены шесть тестовых функций, выполняющих следующие сценарии:

| Сценарий | Ожидаемый результат |
|---|---|
| Повтор записанного настоящего Noise-хендшейка | Отказ без ответного хендшейка |
| Хендшейк со старым временем или временем далеко в будущем | Отказ без записи в память повторов |
| 32 одновременные копии одного сообщения | Защита от повторов принимает ровно одну |
| Изменение шифротекста или тега аутентификации | Поток закрывается, данные не выдаются |
| Повтор или перестановка зашифрованных кадров | Поток закрывается, ошибочный кадр не выдаётся |
| Кадр из другой сессии | Отказ расшифровки и закрытие потока |
| Неадминистративные токены на административных маршрутах | 401/403, включая выдачу ключей, резервную копию и обновление |
| Попытка удалить покупателя без права записи | Отказ; покупатель остаётся доступен администратору |
| Админский токен или подписка вместо токена ноды | Отказ; собственный токен ноды работает |

Источники: [атаки на VP1](../../internal/vp1/attack_security_test.go),
[разделение прав API](../../internal/panel/authorization_security_test.go).
Проверки выполняются на локальных тестовых соединениях и временной базе;
живые серверы не атакуются. Тесты снимков и обновлений существовали раньше:
теперь они дополнительно выполняются с детектором гонок в отдельном задании.

```sh
go test -count=1 -v ./internal/vp1 ./internal/panel -run '^TestSecurity'
go test -race -count=1 -timeout=10m ./internal/vp1 ./internal/users ./internal/panel ./internal/nodesync ./internal/updater
```

Успех означает, что перечисленные сценарии пройдены в указанной конфигурации.
Это не независимый аудит, не нагрузочный DDoS-тест и не проверка утечек
DNS/IPv6 на реальном телефоне. Число зелёных заданий не является рейтингом безопасности.

[Отчёт первого сканирования и фаззинга от 26.09.2026](2026-09-26/README.md).
Длительность исторических прогонов в нём — 30 секунд; новые задания CI используют 60.
