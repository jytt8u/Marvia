# Проверка кандидата 0.13.0-alpha.4

Дата: 5 октября 2026 года. Кандидат локальный, `versionCode=10008`.
Выпуск 1.0 отложен; исторические метки не изменяются.

## Состав

- Исправления перенесены в основную копию на D с сохранением функций alpha.3:
  информации продавца, фонового обновления, DoH и замера текущей ноды без
  дополнительного рукопожатия.
- Android реагирует на смену внешней сети; прежние замеры и подключения
  отменяются, запоздалый запуск не возвращает уже остановленный VPN.
- Пул отменяет незавершённый дозвон при закрытии; супервизоры ожидают
  восстановления сети без необходимости ждать прежнего периодического таймера.
- Имя кэша чужой подписки использует весь SHA-256; тело также связано с
  отпечатком адреса. Несовпадающий и старый непривязанный кэш не используется.
  Удаление подписки убирает текущий и прежний короткий файл.
- Кэш с датой из будущего не считается свежим. Это привязка к подписке,
  а не шифрование или защита от произвольного изменения локальных файлов.
- Кнопки загрузки README ведут на публичную alpha.2 вместо черновика alpha.3.

## Регрессии

До изменения кэша воспроизведены совпадение четырёхбайтовых имён для двух
разных URL, выдача данных чужой подписки из свежего и резервного кэша, а также
бесконечная свежесть даты из будущего. После изменения эти проверки проходят.

Сетевые тесты проверяют отмену операций прежней сети, отказ публикации старого
RTT, восстановление, закрытие незавершённого дозвона и сообщение мобильного
ядра. Сценарий замера сохраняет новый путь измерения активной ноды через её
текущий пул.

## Автоматические проверки

Завершены:

- `go test ./...`, `go vet ./...`, `go build ./...` — успешно; вывод сборки
  находится вне репозитория на D.
- `go test -race ./internal/client ./internal/foreign ./internal/tunnel ./mobile
  ./internal/panel` — успешно.
- `govulncheck` для Windows и Linux по всем пакетам, для Android arm64 по
  `./mobile` — 0 известных уязвимостей в вызываемых символах и импортируемых
  пакетах. Есть модульное уведомление GO-2026-5932 о `x/crypto/openpgp`;
  этот пакет проект не импортирует. Это не полный аудит новой панели.
- Свежий `gomobile bind` для arm64 / arm и Android API 24 — успешно.
- Gradle `testDebugUnitTest assembleRelease` — успешно: 72 теста, 0 ошибок.
  Есть предупреждения о прежнем использовании deprecated `scaledDensity`.
- APK: `io.marvia.android`, версия `0.13.0-alpha.4`, код `10008`, minSdk 24,
  targetSdk 36, архитектуры `arm64-v8a` и `armeabi-v7a`. `apksigner verify`
  подтверждает подпись; SHA-256 сертификата совпадает с публичным APK:
  `53eb5bd44a381cbae19b7606ef20919e33dffb260d49f2d4ad868885364d7e82`.
- Windows: собраны GUI EXE, переносимый ZIP с Wintun и установщик.
  Упаковщик проверил сумму официального архива и подпись WireGuard у DLL.
  Изолированный тест установщика проверил установку, повторную установку,
  удаление и сохранение постороннего документа в папке с пробелами.
  Этот тест не меняет системный реестр и не заменяет установку обычного
  пользователя с UAC, ярлыками и реальным подключением.

Кандидат собран локально, не опубликован как выпуск GitHub и не имеет
Sigstore-подписи CI. Подпись APK подтверждает ключ издателя, а не независимое
сопоставление бинарного файла с исходниками.

Первый полный запуск выявил служебные копии трёх Go-файлов в игнорируемой
папке `bin/webhooks-transfer`: Go воспринимал их как самостоятельный неполный
пакет. Папка сохранена вне дерева исходников, в каталоге сборки на D;
исходники и патч не удалены. Это локальное препятствие проверке, а не
исправление вебхуков в продукте.

## Что эта проверка не подтверждает

Новый APK ещё нужно проверить на реальном устройстве: смена Wi-Fi / LTE,
остановка в момент запуска, камера и фон. Тесты не доказывают устранение
скачков 70–500 мс на МегаФоне. Нужны сопоставимые измерения прямого доступа и
VPN; результаты испытаний 1 октября не считаются испытаниями этого кандидата.

Чистая установка Windows и VPS, восстановление внешней копии, доставка
вебхука настоящему получателю и полная проверка DNS / IPv6 остаются отдельными
критериями перед beta и 1.0. План: [дорожная карта](../roadmap.md).
